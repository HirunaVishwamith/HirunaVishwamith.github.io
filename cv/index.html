Projects

  • 2025.01 - 2025.11
    Chiron — Out-of-Order RISC-V Processor
    A fully-verified out-of-order RV64IMA RISC-V core in Chisel with register renaming, an 8-entry issue queue, a 16-entry reorder buffer, TAGE branch prediction, and a non-blocking coherent cache hierarchy. Verified instruction-by-instruction in lock-step against a golden C++ model; passes all 84 RISC-V ISA tests and boots Linux.
    • Out-of-order microarchitecture
    • Lock-step verification
    • Chisel
    • Boots Linux
  • 2024.07 - 2025.07
    Cache-Coherent, Out-of-Order Multicore RISC-V CPU
    Led the design of an end-to-end out-of-order, cache-coherent multicore RISC-V processor taken from RTL to FPGA, capable of running bare-metal C programs and booting Linux in multicore mode. Included an Instruction Fetch Unit with a TAGE branch predictor and a multi-threading benchmark suite.
    • Cache coherence
    • Out-of-order multicore
    • FPGA
    • RISC-V
  • 2025.08 - 2025.11
    ASTRA — LEO Satellite Network Simulator
    A physics-accurate Low Earth Orbit constellation simulator in pure C11 with a hand-rolled OpenGL renderer. Couples real Kepler orbital mechanics to per-timestep routing (Dijkstra, distance-vector); validated to machine precision (3e-12 km orbital parity, bit-exact routing over 30k+ paths) and ThreadSanitizer-clean.
    • Orbital mechanics
    • Routing & networking
    • C11 systems programming
    • OpenGL
  • 2024.01 - 2024.06
    Parameterized SIMD Processor for Matrix Operations
    A fully parameterized SIMD processor with a custom ISA for matrix multiplication, addition, and subtraction, built on a 4-stage pipeline in Verilog and deployed on a ZYBO Z7 FPGA with AXI/DMA integration.
    • Custom ISA
    • SIMD
    • Verilog
    • FPGA
