### Project Overview

The **Analog Function Generator** was developed as the **final project for the third-semester laboratory practice module**, demonstrating the ability to apply **practical electronics knowledge** to a complete hardware design.
This project delivers a **versatile signal source** capable of generating **sine**, **triangular**, **sawtooth**, and **square waves** with an **adjustable duty cycle**, covering a frequency range from **20 Hz to 20 kHz**.

Through the design, construction, and testing phases, this project provided valuable hands-on experience in **analog circuit design**, **signal shaping**, and **waveform synthesis** using **operational amplifiers**.

---

### Motivation

The motivation behind this project was to **bridge theoretical learning with practical circuit implementation**, reinforcing core electronics concepts.
By building a function generator from the ground up, I deepened my understanding of **op-amp behavior**, **feedback configurations**, and **waveform generation techniques**.

This project also served as a foundation for exploring **digital waveform generation** in future work, combining analog precision with digital control flexibility.

---

### Key Features

* **Multiple Waveform Generation:**
  Produces **sine**, **square**, **triangular**, and **sawtooth** waveforms.

* **Adjustable Frequency and Duty Cycle:**
  Frequency range from **20 Hz to 20 kHz**, with tunable duty cycle control.

* **Op-Amp Based Design:**
  Utilizes **operational amplifiers** for waveform shaping and amplitude control.

* **Hands-On Learning:**
  Strengthened practical skills in circuit debugging, signal integrity, and component selection.

* **Educational Impact:**
  Served as a **capstone analog project**, consolidating essential knowledge in **electronics engineering**.
